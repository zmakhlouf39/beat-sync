# beat-sync
Upload a track, detect beats, export cut markers for Premiere
- **Premiere Version**: 25.3.0
- In: WAV, MP3, AAC, or OGG, analysed entirely in the browser
- Out: editable markers on a waveform; CSV and Premiere-ready XML at 23.976-30fps
